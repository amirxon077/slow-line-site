Personal automation tool

FinanceFlow Studio

A small private tool that publishes finished videos to its operator's own YouTube channels. It is not a product, it has no users other than its operator, and nothing is offered for sale here.

What it does

The tool assembles a video from material its operator has prepared — a written script, a synthesised narration track, a generated background image and a synthesised ambient soundtrack — and then uploads that finished file to a YouTube channel owned by the same person, filling in the title, description, tags and thumbnail along the way.

Which Google data it touches

Only the operator's own YouTube account, and only to upload. The tool requests these scopes:

  • youtube.upload — to upload a video file to the channel
  • youtube — to set the thumbnail and add the video to a playlist

It does not read viewer data, comments, subscriber lists or analytics, and it does not touch any other Google service.

Privacy: the tool collects no personal data from anyone. See the privacy policy for the details.

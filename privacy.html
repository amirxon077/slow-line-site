FinanceFlow Studio

Privacy policy

Last updated 28 September 2026

Short version

FinanceFlow Studio is a private tool used by one person to upload videos to his own YouTube channels. It has no other users, no sign-up, no accounts and no visitors to serve. It collects no personal data from anyone.

What data the tool accesses

The tool authenticates with Google as its operator, Amirxon Olimov, and uses that access only to publish to YouTube channels he owns. The scopes it requests are:

  • https://www.googleapis.com/auth/youtube.upload — upload a video file
  • https://www.googleapis.com/auth/youtube — set the thumbnail, add the video to a playlist

It does not read or store viewer information, comments, subscriber lists, watch history or analytics, and it does not access any Google service other than YouTube.

What is stored, and where

The only credential the tool keeps is an OAuth refresh token for the operator's own Google account. It is stored as an encrypted secret in the operator's private GitHub repository and is used solely to obtain short-lived access tokens at upload time. Video files and their metadata are produced during a build and discarded when that build's temporary storage expires.

What is shared

Nothing is sold, shared or transferred to anyone. Data flows in one direction only: from the operator's build environment to the operator's own YouTube channel.

Third parties

Producing a video involves services the operator subscribes to — GitHub Actions for computing, and text and speech providers for generating the script and narration. These receive only material the operator supplies. None of them receive personal data about anyone, because the tool holds none.

Removing access

The operator can revoke the tool's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored refresh token.

Children

The tool is not directed at children and is not usable by anyone other than its operator.

Changes

If what the tool does changes, this page is updated and the date above changes with it.
